# Kube Console website

The public page for Kube Console, a Mac app for everyday Kubernetes work:
shells, logs and app health with buttons instead of kubectl, on GKE, EKS, AKS
or any kubeconfig.

**Site:** https://sibinms.github.io/kube-console-site/

The page lives in `docs/` and is served by GitHub Pages from the `main`
branch. Screenshots are taken from the app's demo mode, which uses made-up
data only.

Want to try the app? [Request early access](https://github.com/sibinms/kube-console-site/issues/new?title=Early%20access%20request).
